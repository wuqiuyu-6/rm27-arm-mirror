# 关节映射标定

目标：让仿真臂的姿态与真机一致。映射式：

```
sim_q[i] = sign[i] * raw_q[i] + zero[i]        （rad）
```

## 为什么需要标定

固件发出的 `q` 是**它自己的模型**（HevRobot v1.0，`q_DH = q_URDF`）坐标；本仓库的 MJCF 来自
`model/arm_v7` 的 URDF 导出。两边虽然都是"关节角"，但：

1. 关节轴正方向可能整体相反（URDF 里 `axis` 的方向约定差异）；
2. 个别关节的机械零位不同（装配/零点标定差异）；
3. 仿真模型的关节范围不一定覆盖实机全行程。

## 已确认的取值（2026-11）

| 关节 | sign | zero | 依据 |
|---|---|---|---|
| joint1 | −1 | 0 | 整体反向 |
| joint2 | −1 | 0 | 整体反向 |
| joint3 | −1 | 0 | 整体反向；实机与模型零位差 180° 已通过对比确认取 0 时对齐 |
| joint4 | −1 | 0 | 方向单独复核过 |
| joint5 | −1 | 0 | 整体反向 |
| joint6 | −1 | 0 | 整体反向 |

> 历史：曾一度把 joint4 设为 +1、joint3 设为 ±90°，实测姿态不符后修正为上表。

## 复标步骤

1. 把机械臂摆到**已知姿态**（例如全零位，或贴刻度）；
2. 运行 `arm-mirror print`，记录六个数；
3. 与仿真模型的期望角度比较：
   - 数值相等但**方向相反** → 该轴 `sign = -1`；
   - 数值差**固定角度** → 调该轴 `zero`（`zero = 期望 - sign*raw`）；
4. 改 `config/joints.yaml`，重跑 `arm-mirror view` 目视确认；
5. 六个轴逐一验证后，把该姿态与六个数记到本文件（便于回归）。

## 常见坑

- **只改 sign 不改 zero**：对"整体反向 + 零位差 π"的轴，只改 sign 会得到镜像姿态，看起来"能对上"但
  端点处不对；先确认零位再定 sign。
- **用模型范围去夹实机值**：实机可能超出 MJCF 的 `range`（例如 joint3），默认**不夹**；
  要夹就加 `--clamp`，并明确这会改变显示姿态。
- **CRC 未校验**：坏帧被当成数据会让臂瞬间跳一下；本工程默认校验，排查时才用 `--no-crc`。
