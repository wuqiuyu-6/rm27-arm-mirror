# 装配流程与规则依据

## 流程（与轨迹中的阶段一一对应）

| 阶段 | 动作 | 驱动方 |
|---|---|---|
| home / pre / approach | 底盘驶入、预备位、接近 | 机械臂 |
| close / settle / lift | 夹紧、提起 | 机械臂（摩擦夹持） |
| roll / staging | 翻转成水平、移到销前 | 机械臂 |
| insert / insert-hold / insert2 | 插入 100 mm、竖直上抬 100 mm | 机械臂 |
| P | 绕 P 轴 90° | 机械臂 |
| retreat | 松手退回 | 机械臂 |
| Q | 绕 Q 轴 51.6° | 核心机构（`c_joint3`） |
| done | 保持 2 s | 机构 |

## 规则依据

`reference/rm27-research/rules/RoboMaster2027_规则手册V1.0.0.pdf`（文件页 = 印刷页 + 1）：

| 页 | 内容 |
|---|---|
| 88 | 步骤 4：以 P 轴为旋转轴，把能量单元向上旋转 90° |
| 89 | 步骤 5：绕 Q 轴转到指定角度；停留 >2 s 后机构以约 0.5 N·m 保持 |
| 90 | 装配时需操作能量单元，而不是科技核心的可动结构 |

## 关键设计决定

1. **夹持必须是摩擦**：`grasp` weld 故意禁用，单元靠夹垫摩擦提着；
2. **销孔/磁吸用 `mount` weld 表达**：插到位瞬间按当前相对位姿激活；
3. **核心关节带保持力矩**：`c_joint2/c_joint3` 的库仑摩擦 = 0.5 N·m（规则第 89 页），
   松手后销子不会因单元重量下垂；
4. **Q 由机构驱动**：P 转完后夹爪开合轴与 Q 轴重合，平行两指无法传递绕该轴的力矩
   （实测臂驱动只能到 25~29° 就打滑）。

| 指标 | 目标 | 实测 |
